# Pneuma

Игра про робота, который исследует процедурно сгенерированную планету, добывает процедурные ресурсы и строит из логических примитивов и макроблоков машины для их переработки.

Проект начат в Antigravity 2.0 и перенесён в Codex. Рабочий прототип сделан на Godot в 2D, визуальное направление на будущее — low-poly.

Подробности концепции: [docs/concept.md](docs/concept.md).
