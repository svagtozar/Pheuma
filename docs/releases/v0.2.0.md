Второй релиз Pneuma. Как и раньше, главное здесь — 3D-версия: `Pneuma3D` для Windows и сборка для Steam Deck. 2D-игра лежит рядом.

**Что нового с v0.1.0**
- Рельеф на Voxel Tools: гладкие пещеры и склоны, дальние участки проще по детализации
- Движок Godot 4.7.2
- Прицел в центре экрана: бур грызёт туда, куда смотришь, лунки плавные
- Инвентарь (I / LB): можно брать из бака, копать с полным бункером почвы
- Каталог стройки и панель быстрого выбора, трубы тянутся мышью, новые детали логистики
- Стройка за пределами площадки завода
- Бег, крюк-рука, камера в пещерах, робот сам выбирается, если застрял
- Жидкости больше не висят в воздухе, река над пещерой лежит на каменном своде
- Края луж, лавы и корки сглажены, без квадратных клеток
- Автообновление: лаунчер на Steam Deck и `Pneuma3D.cmd` на Windows сами скачивают новые файлы

**Файлы**
- `Pneuma3D-…-windows-x86_64.zip` — 3D для Windows
- `Pneuma3D-…-steamdeck.tar.gz` — Steam Deck, как ставить — в README внутри архива
- `Pneuma-…-windows-x86_64.zip`, `Pneuma-…-linux-x86_64.tar.gz` — 2D-игра
