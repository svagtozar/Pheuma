Первый релиз Pneuma. Главное здесь — 3D-версия: `Pneuma3D` для Windows и сборка для Steam Deck. Обычная 2D-игра лежит рядом, как и раньше.

**Что нового с прошлой тестовой сборки (27.09, вечер)**
- Планета — настоящий шар: её можно обойти целиком, горизонт закругляется
- Смена дня и ночи, новое небо по тегам планеты, ночью горит фара
- Жидкости: плавучесть, вид из-под воды, лава и кислота ведут себя по-разному
- Инопланетная органика на живых планетах: мох, кораллы, трубчатые черви, пузыри
- Планеты не повторяются: облик заметно меняется от сида, следующая планета случайная
- Новый облик всех машин завода и анимации их работы
- Финал целей планеты: пусковая шахта, маяк и купол
- Правки темпа и баланса по замерам бота
- Deck: меньше вызовов отрисовки на заводе

**Файлы**
- `Pneuma3D-…-windows-x86_64.zip` — 3D для Windows
- `Pneuma3D-…-steamdeck.tar.gz` — Steam Deck, как ставить — в README внутри архива
- `Pneuma-…-windows-x86_64.zip`, `Pneuma-…-linux-x86_64.tar.gz` — 2D-игра
