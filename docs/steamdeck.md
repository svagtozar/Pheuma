# Pneuma на Steam Deck

Сборка для проверки: игра стартует сразу в 3D-режиме, робот управляется геймпадом.
Экран 1280×800, полноэкранный режим, тени облегчены под Deck.

## Установка

1. Перейдите в режим рабочего стола (Steam → Питание → Переключиться на рабочий стол).
2. Распакуйте архив `Pneuma-…-steamdeck.tar.gz`, например в `~/Games/Pneuma`.
3. Если файлы не запускаются, сделайте их исполняемыми: ПКМ по `pneuma.sh` и
   `Pneuma.x86_64` → Свойства → Права → «Выполнять как программу»
   (или `chmod +x pneuma.sh Pneuma.x86_64`).
4. В Steam: «Добавить игру» → «Добавить стороннюю игру» → «Обзор…» → `pneuma.sh`
   (в диалоге выберите тип файлов «Все файлы», если его не видно).
5. Вернитесь в игровой режим и запустите Pneuma из библиотеки («Не из Steam»).

## Обновления

Качать архив заново больше не нужно. `pneuma.sh` при каждом запуске сверяется
с последней сборкой на GitHub и докачивает только изменившиеся файлы: обычно это
`Pneuma.pck` (~12 МБ), движок `Pneuma.x86_64` (~70 МБ) меняется лишь при
смене версии Godot. Нет интернета — игра просто запустится как есть.
Текущая сборка написана в главном меню под названием, журнал — в `update.log`.

Откуда брать обновления, задаёт файл `channel.txt` рядом с игрой (одно слово):

| Канал | Что приходит |
|---|---|
| `nightly` (по умолчанию, файла можно не создавать) | каждая сборка ветки main |
| `stable` | только релизы v* |
| `off` | ничего, обновления выключены |

Если в Steam уже добавлен старый `Pneuma.x86_64`, распакуйте этот архив поверх
и в свойствах игры в Steam поменяйте «Цель» на `pneuma.sh` — это нужно один раз.

Совместимость (Proton) включать не нужно: это родная Linux-сборка.
В настройках контроллера игры выберите шаблон «Геймпад» (Gamepad), если Steam
предложит другой.

## Управление

| Кнопка | Действие |
|---|---|
| Левый стик | ходьба (скорость зависит от наклона) |
| Правый стик | камера |
| L3 (нажать левый стик) | бежать быстрее |
| R2 | бур |
| L2 | выстрелить кистью и подтянуться, ещё раз — отпустить |
| D-pad вверх / вниз | приблизить / отдалить камеру |
| View (☐☐, слева) | другая планета |
| Menu (☰, справа) | выход |

С клавиатуры: WASD, Q/E, Shift, F, G, Tab — другая планета, Esc — выход.
