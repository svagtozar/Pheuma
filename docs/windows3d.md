# Pneuma3D для Windows

Сборка для проверки 3D-режима: игра стартует сразу в 3D, управление — геймпадом
или клавиатурой.

## Установка и запуск

1. Распакуйте архив `Pneuma3D-…-windows-x86_64.zip` в любую папку, например
   `C:\Games\Pneuma3D`.
2. Запускайте игру через `Pneuma3D.cmd`. На него удобно сделать ярлык на рабочем
   столе или добавить его в Steam как стороннюю игру.
3. Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» →
   «Выполнить в любом случае».

## Обновления

Качать архив заново больше не нужно. `Pneuma3D.cmd` перед каждым запуском
сверяется с последней сборкой на GitHub и докачивает только изменившиеся файлы:
обычно это `Pneuma3D.pck` (~12 МБ). Движок `Pneuma3D.exe` (~95 МБ) меняется лишь
при смене версии Godot. Нет интернета — игра просто запустится как есть.
Если запустить `Pneuma3D.exe` напрямую, обновления не проверяются.
Текущая сборка написана в главном меню под названием, журнал — в `update.log`.

Откуда брать обновления, задаёт файл `channel.txt` рядом с игрой (одно слово):

| Канал | Что приходит |
|---|---|
| `nightly` (по умолчанию, файла можно не создавать) | каждая сборка ветки main |
| `stable` | только релизы v* |
| `off` | ничего, обновления выключены |
